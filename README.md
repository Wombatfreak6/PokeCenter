# PokeCenter
A feature-rich Pokémon web application that allows users to explore, search, and interact with Pokémon data, along with a battle simulation system inspired by classic Pokémon games.

---

## 🚀 Features

### 🔍 Search & Discovery
- Search Pokémon by name in real-time
- Instant results powered by API integration

### 🧩 Grid Interface
- Clean, responsive grid layout
- Displays Pokémon with essential stats and visuals
- Designed for smooth browsing experience

### 🎯 Filters & Sorting
- Filter Pokémon based on:
  - Type (Fire, Water, Grass, etc.)
  - Stats (HP, Attack, Defense, Speed)
- Sort Pokémon dynamically for better comparison and analysis

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript  
- Pokémon API (for data)

---

## 🎮 Inspiration

This project draws inspiration from early Pokémon games such as **Pokémon FireRed**, recreating the feel of classic turn-based battles in a modern web interface.
